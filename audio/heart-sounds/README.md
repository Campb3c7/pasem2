# Heart Sounds audio

Used by the Cardio Part 1 Heart Sounds tool (`heart-sounds.js`, labels in `data/heart-sounds.js`).

- `class/` — the 10 practice recordings from the Heart Sounds lecture on Canvas, each as sound only (tracks 11-20) and with the lecture talking over it (tracks 1-10). Added at Anna's request (2026-11-02).
- `michigan/` — Additional practice. Heart Sound and Murmur Library, Richard Judge and Rajesh Mangrulkar, University of Michigan Medical School (2015). Licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Files unchanged. Source: https://deepblue.lib.umich.edu/items/d9d03331-12f5-414e-9c19-3c5985bedb49
- `congenital/` — Additional practice. Congenital Heart Disease Sounds, free MP3s from https://teachingheartauscultation.com/heart-sounds-mp3-downloads. File names lower-cased.
